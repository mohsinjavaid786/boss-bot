# Third-party notices

## Dependencies

Dependencies are installed through npm with their own licenses and notices.
React/React DOM, Vite, tsx, Zod, Concurrently and Prettier use MIT licenses;
TypeScript uses Apache-2.0; Lucide React uses ISC. The npm lockfile identifies
exact resolved versions. Preserve dependency notices when redistributing
bundled software. Node.js and its bundled SQLite retain their upstream terms.
